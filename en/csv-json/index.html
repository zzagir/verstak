How to use “CSV ⇄ JSON”

Convert a CSV table to JSON or a JSON array to CSV for Excel. CSV ⇄ JSON online works for free and without registration: open the page, add your data and get the result in a few seconds.

  1. Type or paste your text into the field.
  2. Choose the options — the result updates instantly.
  3. Copy the result or save it as a file.

Questions and answers

Is it free?

Yes. “CSV ⇄ JSON” and every other Verstak tool is free, with no sign-up, watermarks or limits on the number of files.

Does it work on a phone?

Yes, in any modern browser on Android, iPhone, Windows, macOS and Linux. Nothing to install. You can also add the site to your home screen as an app.
