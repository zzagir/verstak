# Верстак — онлайн-инструменты для PDF, изображений и текста

Статический сайт без сервера: 83 инструмента, все файлы обрабатываются в браузере пользователя.
Русская и английская версии, отдельная SEO-страница для каждого инструмента, тёмная тема, офлайн-режим (PWA).

## Запуск и публикация

1. Укажите адрес сайта, счётчики и рекламу в `js/config.js`.
2. Соберите страницы: `node build.js` (нужен только Node.js 16+, без зависимостей).
3. Загрузите папку целиком на любой хостинг статики: Nginx, Apache, GitHub Pages, Netlify, Cloudflare Pages, S3.

Локально: `npx http-server .` и откройте http://localhost:8080.
Можно открыть и `index.html` прямо с диска — тогда сайт работает на одной странице (адреса через `#`), но некоторые функции
(шрифт с кириллицей для PDF, OCR, удаление фона, офлайн-режим) требуют веб-сервера.

После любых изменений в `js/` снова запустите `node build.js` — он пересоздаёт HTML-страницы, `sitemap.xml`, `robots.txt` и `sw.js`.

## Структура

| Путь | Что внутри |
|---|---|
| `js/config.js` | Адрес сайта, Яндекс.Метрика, Google Analytics, коды рекламных блоков, e-mail |
| `js/core.js` | Общие компоненты: загрузка файлов, формы, результаты, ZIP, пакетная обработка, предпросмотр |
| `js/pdf-tools.js` | PDF: объединение, разделение, сжатие, поворот, обрезка, размер страниц, колонтитулы, конвертации |
| `js/pdf-extra.js` | OCR, редактор PDF, подпись, заполнение форм, сравнение двух PDF |
| `js/image-tools.js` | Изображения: сжатие, размер, обрезка, форматы, водяной знак, удаление фона, лица, GIF, фото на документы |
| `js/text-tools.js` | Транслит, раскладка, клавиатура, типограф, сумма прописью, SEO-анализ, шрифты, строки |
| `js/dev-tools.js` | Base64, URL, Морзе, двоичный код, HEX, шифры, хеши, генераторы, JSON, CSV, QR-коды |
| `js/views.js` | Разметка страниц и SEO-тексты (общая для сборки и для режима с диска) |
| `js/i18n.js`, `js/i18n-en.js` | Перевод интерфейса: ключ — русская строка, значение — английская |
| `build.js` | Сборка статических страниц |
| `vendor/` | Библиотеки (pdf-lib, pdf.js, Tesseract, нейросеть удаления фона и др.) — грузятся только когда нужны |

Новый инструмент добавляется вызовом `fileTool({...})` или `tool({...})` в одном из файлов `js/`, затем `node build.js`.
Для английской версии добавьте его строки в `js/i18n-en.js`.

## Размер

Папка `vendor/` весит ~85 МБ, из них ~62 МБ — модель удаления фона и ~10 МБ — словари OCR.
Посетитель скачивает их только при первом использовании этих инструментов.

## Ограничения

- «Сжать PDF» пересобирает страницы как изображения: текст перестаёт выделяться.
- «PDF в Word / RTF / ODT / EPUB / FB2» переносят текст, без картинок и вёрстки.
- «Word / HTML / EPUB / FB2 / TXT в PDF» вставляют текст в PDF картинкой, выделить его нельзя.
- «Удалить фон» и «Размыть лица» работают на нейросетях в браузере: на слабых телефонах медленно.
- Excel, PowerPoint, DjVu, MOBI, XPS, снятие пароля с PDF и улучшение качества фото нейросетью требуют сервера и не реализованы.
